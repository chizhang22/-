## 打开使用

双击 `启动坐标系.cmd`，保持启动窗口运行，然后打开：

http://127.0.0.1:4174

需要 Node.js 24 或以上。当前电脑已安装依赖。也可以在本目录终端运行 `npm run dev`。

首次使用可以选择摄像头观察或纯计时。摄像头模式记录十秒个人参考，之后观察持续姿态变化；用眼观察可独立开启。结束使用会释放摄像头，并将摘要保存到本地数据库。

## 切到后台与接续记录

- 先在前台完成舒适坐姿校准，再切到其他页面或软件。后台目标采样间隔为 200 毫秒，实际频率受浏览器调度影响；前台目标间隔为 80 毫秒，两者另加模型处理耗时。
- 姿态偏移只累计有效采样覆盖的时段。画面冻结或长时间缺帧时重新确认姿态，页面显示画面待恢复。专注总时长按页面存续期间的时间差累计，尚未自动识别电脑休眠；休息时可主动暂停。
- 眨眼统计仅接纳间隔在 250 毫秒以内的有效采样。稀疏画面留空，已有的部分统计窗口会保留，用眼提示仍集中在结束时。
- 真实专注每约 5 秒在浏览器保存轻量摘要，切换页面和离开页面时补存。刷新后可选择接续这段专注，或保存为已结束。摄像头接续后重新校准；页面关闭期间的时间留空。异常退出可能损失最后一个暂存间隔，浏览器调度受限时也可能更长。
- 暂存包含次数、时长与眨眼窗口统计，视频、原始关键点和校准画面均留在实时处理环节。清除网站数据会同时清除尚未入库的暂存，因此请先确认摘要保存完成。
- 保存失败的摘要按记录编号保留，定期、返回页面或网络恢复时重试。本机服务重启后可自动补存。另一个页面正在使用的草稿保持保护；异常退出后通常约两分钟出现恢复入口。
- 摄像头或姿态模型运行中断时，专注计时继续，页面提供重新连接姿态观察按钮。


## 个人记录如何积累

- 随手记：记录工作中的身体感受，保留原话，未填写的程度留空。
- 聊一聊：把近期数据交给模型分析，模型可查询记录、保存明确表达的感受和偏好、提出提醒调整。
- 我的记录：查看、修改、删除反馈与记忆，导出本地数据。
- 使用习惯：调整提醒间隔、免打扰时间和字号。

程序统计、用户陈述、待验证规律分开存放。演示模式数据与真实记录区分。姿态和眨眼统计只使用有效观察时间，后台与观察缺失时段单独处理。

## 配置模型服务

当前已接入并行智算云的 GLM-5.3，使用 OpenAI Chat Completions 兼容协议，支持真实工具调用。模型凭证保存在本目录 `.env`，只供后端读取。也保留 Anthropic Messages 兼容协议适配。

也可以复制 `.env.example` 为 `.env`，在本机填写服务地址、凭证和服务商提供的模型 ID：

```dotenv
ZBX_API_PROTOCOL=openai
ZBX_BASE_URL=https://llmapi.paratera.com
ZBX_API_KEY=你的密钥
ZBX_MODEL=GLM-5.3
```

修改后重启启动窗口。本目录 `.env` 优先于旧 Windows 环境变量。密钥只供后端使用，请勿放进网页代码或 `VITE_` 变量。分享项目时排除 `.env` 和 `data/`。

已有配置与连接成功分别显示。只有真实模型响应才标记在线回答；连接失败时显示原因，用户仍可记录感受、查看历史、使用计时和提醒。

已使用 GLM-5.3 完成真实工具调用验证：保存原话反馈、查询历史、计算趋势、提出提醒调整。设置确认后由 30 分钟变为 45 分钟，撤销后恢复。验收使用独立测试数据，与正式个人数据库隔离。

服务商文档：https://ai.paratera.com/document/llm/quickStart/useApi

## 数据与运行边界

- 视频和逐帧关键点仅参与本机实时处理，项目没有视频录制功能。
- 个人摘要、反馈、偏好、聊天与操作记录保存在本机 SQLite 数据库。
- 启用聊天前会说明模型请求的数据范围：用户文字和相关摘要将发送给配置的模型服务。画面和原始关键点不会发送。
- 服务仅监听本机地址。本版面向同一电脑上的个人使用，多人和跨设备使用需要另行设计账号与权限。
- 浏览器后台可能降低采样频率、延迟通知或冻结页面。本版会尝试后台观察，并如实保留有效覆盖范围；网页无法保证最小化、锁屏或节能模式下持续检测。
- 正面单摄像头只能估计相对变化；眨眼统计受光线、眼镜与采样性能影响。真实使用可靠性需要人工试用验证。
- 健康建议用于工作习惯观察，动作由有限条目提供，用户可按身体情况选择与跳过。

## 开发与验证

`node scripts/ui-fixture.mjs` 启动隔离验收页面（4176）与内存数据库（4177），模型调用关闭，正式个人数据库保持原样。浏览器实测应使用独立测试地址；普通使用仍访问 4174。

```sh
npm run test
npm run build
npm run dev
```

前端端口 4174，后端端口 4175。`npm run preview` 仅启动构建后的网页，使用 API 时还需在另一个终端运行 `npm run server`。

`npm run probe:model` 仅查询已配置服务的模型列表，输出服务状态和模型名称，隐藏密钥。

`node scripts/live-agent-check.mjs --live` 会调用真实模型并产生 API 用量，使用虚构输入和内存数据库进行工具链验收。日常使用无需重复运行。

核心目录：`src/` 网页与观察逻辑，`server/` 本地数据与 Agent，`server-tests/` 后端测试，`tests/` 观察算法测试。
